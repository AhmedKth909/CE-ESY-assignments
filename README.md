# CE-ESY-assignments
المشروع يطبق Circular Buffer (مخزن دائري) لتخزين محارف (char) بشكل FIFO (أول داخل أول خارج)، مع استخدام مؤشرين:

head: للقراءة
tail: للكتابة
ويتم إعادة التدوير باستخدام % SIZE لتفادي الخروج عن حدود المصفوفة.

init: تهيئة المخزن بجعل المؤشرات والقيمة count تساوي صفر.
isFull: يتحقق إذا كان المخزن ممتلئ (count == SIZE).
isEmpty: يتحقق إذا كان المخزن فارغ (count == 0).
writeBuffer: يضيف محرف إلى المخزن عند tail ثم يحرك المؤشر ويزيد count، مع منع الكتابة عند الامتلاء.
readBuffer: يقرأ محرف من head ثم يحرك المؤشر وينقص count، مع منع القراءة عند الفراغ.
clearBuffer: يعيد ضبط المخزن لحالة البداية (تفريغ كامل).
